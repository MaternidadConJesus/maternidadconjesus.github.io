Política de privacidad

Última actualización: 4 de octubre de 2026

1. Quiénes somos

«Maternidad con Jesús» es un canal de YouTube de música cristiana. Esta política explica cómo trata los datos la aplicación «Maternidad con Jesus - Publicador» (en adelante, «la aplicación»), una herramienta interna que usa el propio canal para subir sus vídeos a YouTube. Contacto: maternidadconjesus@gmail.com.

Servicios API de YouTube

Esta aplicación utiliza los Servicios API de YouTube. Al usarla, aceptas quedar sujeto a las Condiciones del Servicio de YouTube. El tratamiento de datos por parte de Google se rige por la Política de Privacidad de Google.

2. Quién usa la aplicación

La aplicación no está abierta al público: solo la usan las personas que gestionan el canal, para su propia cuenta de YouTube. No recoge datos de visitantes, suscriptores ni de ninguna otra persona.

3. Qué datos de Google usa y para qué

La aplicación solicita únicamente el permiso de Google «Gestionar tus vídeos de YouTube» (youtube.upload). Lo usa exclusivamente para:

  • subir al canal los vídeos que el propio canal ha creado y aprobado;
  • indicar el título, la descripción, la miniatura, la privacidad, si el contenido está dirigido a niños y si contiene contenido sintético (creado con inteligencia artificial).

No lee, descarga ni modifica otros vídeos, comentarios, suscriptores, estadísticas ni datos personales.

4. Dónde se guardan los datos

El permiso de acceso (token de OAuth) se guarda solo en el ordenador del canal, protegido y fuera de cualquier repositorio público. No se envía a terceros, no se vende y no se usa con fines publicitarios. Se puede revocar en cualquier momento desde myaccount.google.com/permissions.

5. Compartición con terceros

Los únicos datos que salen del ordenador del canal son los vídeos y sus metadatos, que se envían a YouTube (Google) para publicarlos. El uso de YouTube se rige por las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

6. Cumplimiento de las políticas de Google

El uso y la transferencia de la información recibida de las APIs de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

7. Conservación, revocación y eliminación

El token se conserva mientras el canal use la aplicación y se elimina del ordenador en cuanto deja de usarse o se revoca. Puedes revocar el acceso de la aplicación en cualquier momento desde la página de seguridad de Google: security.google.com/settings/security/permissions. También puedes pedir la eliminación escribiendo al correo de contacto; se atenderá en un plazo máximo de 7 días. La aplicación no almacena datos de la API de YouTube (no guarda estadísticas, listas ni datos de otros usuarios); solo conserva, en el propio ordenador del canal, el identificador de los vídeos que ha subido.

8. Cambios

Si esta política cambia, se publicará aquí con su nueva fecha.

Privacy Policy (English)

This application uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is governed by the Google Privacy Policy.

Who uses it. «Maternidad con Jesus - Publicador» is an internal tool used only by the people who run the YouTube channel «Maternidad con Jesús», for their own channel. It is not offered to the public and does not collect data from viewers, subscribers or any other person.

Data accessed. It requests only the youtube.upload scope, used exclusively to upload the channel's own approved videos and set their title, description, thumbnail, privacy status, made-for-kids flag and altered/synthetic content disclosure (videos.insert, thumbnails.set). It does not read, download or modify any other videos, comments, subscribers, analytics or personal data.

Storage and sharing. The OAuth token is stored only on the channel's own computer, outside any public repository. It is never sold, shared with third parties or used for advertising. The only data sent out are the videos and their metadata, sent to YouTube for publication. No YouTube API data is stored, other than the IDs of the videos the tool uploaded.

Revocation and deletion. Access can be revoked at any time at security.google.com/settings/security/permissions. Deletion requests can be sent to maternidadconjesus@gmail.com and are handled within 7 days. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
